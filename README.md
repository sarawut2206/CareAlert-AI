
## ระบบทำอะไรบ้าง

### ชั้นที่ 1 — สำหรับนักเรียนทุกคน

- เช็กอินรายวัน (30 วินาที) และรายสัปดาห์ (2 นาที)
- กิจกรรมทักษะชีวิต 9 โมดูล: จัดการความเครียด เรียกชื่ออารมณ์ การสื่อสาร
  การแก้ความขัดแย้ง รับมือ bullying ช่วยเพื่อนอย่างปลอดภัย ขอความช่วยเหลือเป็น
  การนอน และความปลอดภัยออนไลน์
- ปุ่มขอความช่วยเหลือที่กดได้จากทุกหน้าจอ **โดยไม่ต้องล็อกอิน**

### ชั้นที่ 2 — สำหรับนักเรียนที่ต้องการความช่วยเหลือเพิ่ม

- ช่องทาง "เล่าเรื่องของฉัน" (เลือกไม่บอกชื่อได้)
- ช่องทาง "เป็นห่วงเพื่อน" (ไม่ต้องบอกชื่อผู้แจ้ง)
- ชุดคำถามเชิงลึกที่เปิดตามเงื่อนไขโดยอัตโนมัติ
- ระบบจัดการเคสสำหรับบุคลากร พร้อมกำหนดเวลาที่ต้องดำเนินการ
- บังคับให้ครบวงจรก่อนปิดเคส: คุยแล้ว → ยืนยันความปลอดภัย → มีบันทึกการดำเนินการ

### วงจรการทำงาน

```
Detect → Disclose → Validate → Assess → Alert → Intervene → Follow-up
```

## หลักการที่ห้ามละเมิด

1. **ระดับที่ระบบเสนอคือ "ต้องทำอะไรต่อ" ไม่ใช่ "เด็กคนนี้เป็นอะไร"**
2. **ทุกระดับตั้งแต่ 2 ขึ้นไปต้องมีมนุษย์ตรวจสอบ** ระบบไม่ปิดเคสเอง
   และไม่แจ้งหน่วยงานภายนอกโดยอัตโนมัติ
3. **ข้อมูลไม่พอ = "ยังสรุปไม่ได้" ไม่ใช่ "ไม่มีปัญหา"**
4. **ปัจจัยปกป้องใช้วางแผนช่วยเหลือได้ แต่ห้ามใช้ลดระดับ**
5. **นักเรียนไม่เคยเห็นระดับ คะแนน หรือชื่อกฎ** — เห็นเฉพาะข้อความที่ช่วยได้จริง
6. **ทุกกฎอธิบายได้** เปิดดูได้ที่เมนู "กฎของระบบ" ในหน้าจอบุคลากร
7. **ยอมเตือนเกิน ดีกว่าพลาด** — ต้นทุนของการเตือนเกินคือครูคุยกับนักเรียนหนึ่งครั้ง

## เทคโนโลยี

| ส่วน | เทคโนโลยี | เหตุผล |
|---|---|---|
| เซิร์ฟเวอร์ | Node.js + Express | dependency เดียว |
| ฐานข้อมูล | `node:sqlite` (มีมากับ Node) | **ไม่มี native dependency** ติดตั้งบนเครื่องโรงเรียนได้ทันที |
| รหัสผ่าน | `node:crypto` scrypt | ไม่ต้อง build bcrypt |
| หน้าเว็บ | React + Vite + TypeScript | มือถือเป็นหลัก โหลดเร็ว |
| กลไกประเมิน | กฎที่เขียนไว้ล่วงหน้า (deterministic) | ตรวจสอบย้อนหลังได้ทุกเคส |
| ตัวช่วยภาษา | Claude API (ไม่บังคับ ปิดโดยค่าเริ่มต้น) | ใช้ยกระดับได้อย่างเดียว ห้ามลดระดับ |

สำรองข้อมูลง่ายมาก — คัดลอกไฟล์ `server/data/carealert.db` ไฟล์เดียว

## ข้อจำกัดที่ต้องบอกให้ชัด

- ระบบนี้ **ยังไม่ผ่านการทดสอบความตรงเชิงประจักษ์** — เครื่องมือมาตรฐานที่ใช้อ้างอิงผ่านมาแล้ว
  แต่ตัวระบบนี้ต้องผ่านการตรวจสอบแยกต่างหาก ดู [docs/06](docs/06-แผนการตรวจสอบ.md)
- ข้อคำถามในระบบ **เขียนขึ้นใหม่** โดยอ้างโครงสร้างเชิงมิติของ 9S / SDQ / PHQ-A
  แต่ไม่ได้คัดลอกข้อ — ถ้าโรงเรียนได้รับอนุญาตให้ใช้ฉบับจริงแล้ว ให้เพิ่มเป็น template ใหม่
- ระบบนี้ **ไม่ใช่บริการสุขภาพจิต** และไม่ทดแทนจิตแพทย์ นักจิตวิทยา หรือครูแนะแนว
- คลังคำตรวจสัญญาณเป็นภาษาไทยพื้นฐาน **ยังจับคำแสลงและคำเปรียบเปรยไม่ครบ**
  จึงห้ามใช้ผลของมันเป็นเหตุผลเดียวในการสรุปว่า "ไม่มีอะไร"
