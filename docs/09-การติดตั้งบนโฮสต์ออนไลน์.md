# 9. การติดตั้งบนโฮสต์ออนไลน์ (ให้นักเรียนเข้าจากมือถือได้)

GitHub Pages ที่ใช้อยู่เป็นได้แค่ "หน้าสาธิต" — ระบบจริงต้องมีเซิร์ฟเวอร์ที่เปิดตลอด
เอกสารนี้พาไปติดตั้งบนโฮสต์ราคาถูก (~150–250 บาท/เดือน) จนนักเรียนใช้งานจากมือถือได้จริง

**สิ่งที่เตรียมไว้ให้แล้วใน repo:** `Dockerfile` + `.dockerignore` (กันข้อมูลจริงเข้า image)
+ bootstrap สร้างบัญชีแอดมินอัตโนมัติเมื่อฐานข้อมูลว่าง

---

## 9.1 ทางเลือกที่แนะนำ: Railway (ง่ายที่สุด ~ $5/เดือน)

เหมาะกับครูที่ไม่อยากดูแลเซิร์ฟเวอร์เอง — เชื่อม GitHub แล้วระบบ build ให้เอง

1. สมัคร [railway.app](https://railway.app) (ล็อกอินด้วย GitHub ได้เลย)
2. **New Project → Deploy from GitHub repo** → เลือก `sarawut2206/CareAlert-AI`
   — Railway เห็น `Dockerfile` แล้ว build ให้อัตโนมัติ
3. **เพิ่มดิสก์ถาวร (สำคัญที่สุด):** ที่ service → Settings → **Volumes** →
   Mount path = `/data`
   > ไม่ทำข้อนี้ = ข้อมูลนักเรียนหายทุกครั้งที่ deploy ใหม่
4. **ตั้งค่า Variables:**

   | ตัวแปร | ค่า |
   |---|---|
   | `DB_PATH` | `/data/carealert.db` |
   | `JWT_SECRET` | สุ่มเอง: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` |
   | `ADMIN_INITIAL_PASSWORD` | รหัสแอดมินครั้งแรก (ตั้งยาว ๆ) |
   | `NODE_ENV` | `production` |

5. Settings → **Networking → Generate Domain** → ได้ URL เช่น
   `https://carealert-ai-production.up.railway.app` (HTTPS ให้อัตโนมัติ — จำเป็นต่อ PWA)
6. ตั้ง **Healthcheck path** = `/api/health` (ถ้ามีให้ตั้ง)

> Render / Fly.io ก็ใช้ Dockerfile เดียวกันได้ หลักการเหมือนกัน:
> ต้องมี persistent disk + ตั้ง env 4 ตัวข้างบน

## 9.2 ทางเลือก: VPS ธรรมดา (~$4–6/เดือน เช่น DigitalOcean, Vultr, Hostinger)

ควบคุมได้เต็มที่ ข้อมูลอยู่ในมือเราทั้งหมด — ต้องดูแลเองมากขึ้น

```bash
# บนเครื่อง VPS (Ubuntu) — ติดตั้ง Node 24
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs git

git clone https://github.com/sarawut2206/CareAlert-AI.git
cd CareAlert-AI
npm install && npm run build

# ตั้งค่า
cat > server/.env <<EOF
NODE_ENV=production
PORT=8787
JWT_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")
ADMIN_INITIAL_PASSWORD=ตั้งรหัสยาวๆของคุณเอง
EOF

# รันถาวรด้วย systemd
sudo tee /etc/systemd/system/carealert.service <<EOF
[Unit]
Description=CareAlert AI
After=network.target
[Service]
WorkingDirectory=$(pwd)
ExecStart=$(which node) --no-warnings server/src/index.js
Restart=always
User=$USER
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now carealert
```

จากนั้นตั้ง **HTTPS ด้วย Caddy** (ง่ายกว่า nginx+certbot มาก):

```bash
sudo apt install -y caddy
echo "carealert.โดเมนของคุณ.com {
  reverse_proxy localhost:8787
}" | sudo tee /etc/caddy/Caddyfile
sudo systemctl restart caddy
```

> **ต้องมี HTTPS เสมอ** — ทั้งเพื่อข้อมูลนักเรียนและเพื่อให้ติดตั้งเป็นแอป (PWA) ได้

## 9.3 หลัง deploy ครั้งแรก — ทำตามลำดับนี้

1. เปิด URL → ล็อกอิน `admin` + รหัสจาก `ADMIN_INITIAL_PASSWORD`
   → ระบบ**บังคับเปลี่ยนรหัสผ่านทันที**
2. **ผู้ดูแลระบบ → บุคลากร** → สร้างบัญชีครูแนะแนว (จำเป็น — เคสระดับ 3–4 มอบหมายให้ครูแนะแนวอัตโนมัติ) ครูที่ปรึกษา และ ผอ.
3. **นำเข้ารายชื่อนักเรียนจากเครื่องคุณ** (ไฟล์ ม.4.xls อยู่เครื่องคุณ ไม่ได้อยู่บน GitHub):
   ```bash
   BASE_URL=https://ของคุณ.up.railway.app ADMIN_USER=admin ADMIN_PASS=รหัสใหม่ \
     node scripts/import-roster.mjs "ม.4.xls" --level ม.4
   ```
4. **ผู้ดูแลระบบ → ห้องเรียน** → กำหนดครูที่ปรึกษาให้ ม.4/1–13
5. **ผู้ดูแลระบบ → โหมดทดลอง** → ตั้งรหัสเข้าโรงเรียน เลือกห้องนำร่อง → เปิด
6. ทดสอบเองจากมือถือ: เปิด URL → กดชื่อ → ตั้งรหัส → เช็กอิน 1 รอบ

## 9.4 การสำรองข้อมูล (อย่าข้าม)

ข้อมูลทั้งหมดคือไฟล์เดียว: `carealert.db`

| โฮสต์ | วิธีสำรอง |
|---|---|
| Railway | ติดตั้ง `railway` CLI แล้ว `railway ssh` → คัดลอก `/data/carealert.db` ออกมา หรือใช้ฟีเจอร์ Volume backup |
| VPS | `scp user@server:~/CareAlert-AI/server/data/carealert.db backup-$(date +%F).db` ตั้ง cron รายวัน |

เก็บสำเนาไว้ในเครื่องที่โรงเรียน อย่างน้อยสัปดาห์ละครั้งช่วงทดลอง

## 9.5 เช็กลิสต์ความปลอดภัยก่อนแจกลิงก์ให้นักเรียน

- [ ] เปลี่ยนรหัส admin แล้ว (ระบบบังคับอยู่แล้ว)
- [ ] ตั้ง `JWT_SECRET` แล้ว (ไม่ปล่อยให้สุ่มใหม่ทุก restart)
- [ ] URL เป็น **https://** เท่านั้น
- [ ] มีบัญชีครูแนะแนวอย่างน้อย 1 คน และครูรู้หน้าที่ว่าต้องดูคิวเคสทุกวัน
- [ ] โหมดทดลองตั้ง **รหัสเข้าโรงเรียน** แล้ว และเปิดเฉพาะห้องนำร่อง
- [ ] ทดสอบเคสสมมติ 1 รอบจนปิดเคส (ดู docs/05 ข้อ 5.3)
